# Smart Tourism | AI-Powered Landmark Discovery

Smart Tourism is an AI-powered platform for discovering Saudi landmarks and cultural sites, built to close the gap between generic travel information and explanations that actually match who's reading them. Rather than showing every visitor the same static description, the platform uses an embedded AI layer to adjust each explanation to the reader's age group.

##  Project Overview

### Purpose

Most tourism content is one-size-fits-all: the same paragraph for a curious child, a school-age teenager, and an adult researcher. Smart Tourism replaces that with a layer of AI-generated explanation — using Qwen — that reshapes the same underlying facts about a landmark to fit the reader.

### Objectives

- **Accessible Discovery** — Make it fast to search, browse, and land on the right Saudi landmark, whether by name or by category.
- **Audience-Aware Explanation** — Generate a version of each landmark's story that fits the selected age group, without losing accuracy.
- **Dependable Infrastructure** — Build on Firebase and a clear layered architecture so the platform stays stable as features are added.

---

## Key Features

- **Landmark Search** — Search by name or keyword to quickly find a specific landmark.
- **Landmark Details** — A dedicated page per landmark covering history, location, and cultural significance.
- **Explore by Category** — Browse landmarks grouped by type: heritage sites, natural landmarks, historic districts.
- **Personalized AI Explanation** — Qwen generates an explanation adapted to the selected audience: Child, Teenager, or Adult.
- **AI Tourism Assistant** — Ask an open-ended question and get pointed toward landmarks that match your interests.
